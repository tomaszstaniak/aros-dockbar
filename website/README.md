# Dockbar website

The static product website is published at https://tomaszstaniak.github.io/aros-dockbar/.
GitHub Actions deploys only this directory after changes on main.

For a local preview, run `python3 -m http.server 8765 --directory website` from the repository root.

Keep feature descriptions aligned with the public usage and widget guides. Update the version and three archive URLs when publishing a new release. Screenshots retain their original version captions. The grouped workspace is an illustration using the project's original MIT-licensed SVG icons; it is not a screenshot. Other screenshots are the reviewed images also used in the project README.
