# Documentation

AROS Dockbar is a first visual prototype for stock x86_64 ABIv11: native
launchers, an SVG Tools icon, hover labels, separators, desktop icon drops and
a live clock. It is not yet a release or a configurable multi-dock system.

- [Development and usage](development.md): build variables, commands, runtime
  options, pin-file behavior and verified target scope.
- [SVG dependency](svg-dependency.md): generated headers, separate runtime
  library, pixel ownership and packaging/provenance boundaries.
- [Assets](../assets/README.md): original SVG sources and shipped locations.
- [Scripts](../scripts/README.md): build and host test entry points.

A group popup, multiple docks, general configuration and an extension API are
future work. Public instructions are self-contained; private research and raw
run evidence are kept outside this repository.

- [Applets and Weather](applets.md): experimental package API, installation, provider protocol and author workflow.
