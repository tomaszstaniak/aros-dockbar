# Documentation

Dockbar provides configurable docks, drawer panels, application groups and widgets for AROS. Released packages support mainline x86_64, ABIv11 x86_64 and Raspberry Pi aarch64, with SVG icons and Weather.

- [Development and usage](development.md): build inputs, packaging, controls and configuration.
- [Widgets and Weather](applets.md): installation, settings, package format and provider protocol.
- [SVG dependency](svg-dependency.md): renderer interface, ownership and provenance.
- [Application folder metadata](application-folder.md): the manifest used by arospkg.
- [Assets](../assets/README.md): artwork sources and licences.
- [Scripts](../scripts/README.md): build, test and packaging entry points.

For downloads, screenshots and installation, start with the [project README](../README.md).
